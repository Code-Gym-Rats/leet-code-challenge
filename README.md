## Regras e Como Participar:
1.  **Puxe a `main`:** Antes de começar um novo desafio, sempre faça `git pull origin main` para ter a versão mais recente.
2.  **Crie sua branch:** Para cada dia de desafio, crie uma branch a partir da `main` com o padrão `dia-XX-seu-nome` (ex: `dia-01-arthencia`).
3.  **Resolva os problemas:** Crie uma pasta `desafio-XX` (ex: `desafio-01`) na **raiz do repositório**. Dentro dela, adicione **um único arquivo de solução por problema**. O nome do arquivo deve ser **seu nome de usuário GitHub em minúsculas** (conforme a lista `DEVELOPERS` no script) **seguido da extensão da linguagem** (ex: `desafio-01/arthencia.js`, `desafio-01/adriel.py`).
4.  **Abra um Pull Request (PR):** Quando terminar suas soluções para o dia, faça `git add .`, `git commit`, `git push` e abra um PR da sua branch para a `main`.
5.  **Marque o checklist e comente na Issue:** Vá para a *issue* do dia. Marque seu nome no checklist (para acompanhamento visual) e adicione um comentário sobre seu desempenho, desafios, aprendizados, etc.
6.  **Merge dos PRs:** Ao final do prazo de 24 horas (ou o prazo definido), os PRs serão mergeados na `main` por um responsável. **O ponto no ranking é contabilizado quando seu PR é mergeado!**
